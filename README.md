# VELOTEX 3D

High-tension 3D supercar racing game featuring 5 themed races, selectable 1st-person driver cockpit & 3rd-person chase cameras, NOS boost, dynamic obstacles, procedural Web Audio engine synthesis, and full Korean / English localization.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
